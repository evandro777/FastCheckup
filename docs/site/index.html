FastCheckup

A light and fast system inspector: what is slow, large, unused or exposed, and a button for each finding.

GitHub · Releases

Early version. Tested on Linux Mint Cinnamon. The Flatpak is not sandboxed: it relaunches itself on the host, because an inspector inside a sandbox would only see its own files and programs.

What it does

Written in Rust with Slint, software rendering only, no async runtime. It reports; you act on each item one at a time (there is no "fix all").

SpeedStartup entries, services and the boot breakdown, and what is using CPU and memory right now.
SpaceCaches, build folders, old installers, the journal, Docker, the Trash and leftovers of removed software, sorted by how safe they are to clean.
SafetyDisk health, open ports, persistence files, browser add-ons and failed logins. Report only.
AppsInstalled Debian, Flatpak and AppImage apps with size and last use; uninstall one.

Install with Flatpak (updates itself)

This remote keeps FastCheckup updated with flatpak update and your software centre:

flatpak remote-add --system --if-not-exists fastcheckup https://evandro777.github.io/FastCheckup/fastcheckup.flatpakrepo
flatpak install --system fastcheckup io.github.evandro777.FastCheckup

Use --system: Linux Mint's Update Manager only looks at system-wide Flatpaks. The runtime comes from Flathub. The remote is GPG-signed, but the key lives in the source repository, so it is only as trustworthy as that.

Or the AppImage or the .deb

Download FastCheckup-<version>-x86_64.AppImage or the .deb from the latest release. The AppImage uses the fontconfig, xkbcommon and X11 libraries already on your system.

Run one of them, not several: they use different data folders.
